## 可识别的区域角色

| 角色 | 说明 | 典型特征 |
|------|------|----------|
| SearchArea | 搜索/筛选区 | 包含输入框、下拉框、搜索按钮 |
| ActionGroup | 工具栏按钮组 | 新增、导出、刷新等操作按钮 |
| DataGrid | 数据表格主体 | 包含表头行和数据行 |
| PaginationBar | 分页器 | 页码、每页条数等 |
| FormSection | 表单区块 | 包含标签和输入控件的组合 |
| FormActions | 表单操作区 | 提交、取消、重置等按钮 |
| ChartArea | 图表区域 | 折线图、柱状图、饼图等 |
| StatCard | 统计卡片 | 数值展示、趋势指标 |
| Header | 页面头部 | 标题、面包屑、全局操作 |
| Sidebar | 侧边栏 | 导航菜单、过滤器 |
